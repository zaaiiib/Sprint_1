Desi Nuts 🥜

Authentic, premium quality, hand-picked nuts and dry fruits with a rich South Asian heritage.

Welcome to the official repository for Desi Nuts, an e-commerce and brand platform dedicated to bringing traditional, high-quality dry fruits, seeds, and exotic snack mixes straight from local farms to your doorstep.

🚀 About the Project

Desi Nuts is a modern web application designed to bridge the gap between traditional artisanal dry fruit vendors and digital-first consumers. The platform offers a seamless shopping experience featuring product discovery, user authentication, a dynamic cart and checkout system, and an admin dashboard for inventory management.

Key Features

Catalog & Filtering: Browse through an extensive collection of almonds, cashews, pistachios, walnuts, and special festive gift hampers with advanced filters (price, origin, weight, and category).

User Authentication: Secure sign-up, login, and profile management for personalized shopping experiences and order history tracking.

Cart & Secure Checkout: Smooth state-managed cart functionality paired with simulated payment gateways.

Admin Dashboard: Real-time inventory tracking, order status updates, and product addition/deletion.

Responsive Design: Fully optimized for mobile, tablet, and desktop devices with a rich, culturally inspired aesthetic.

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript

Backend: .NET (C# / ASP.NET Core Web API)

Database: SQL Server / Relational SQL Databases
